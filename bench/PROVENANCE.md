# Provenance of the answer files

## What these files are

`answers_ungrounded.json`, `answers_grounded.json` and `answers_framed.json` are the verbatim JSON
output of one language model answering the 24 items of `questions.json` under the three prompts in
this directory. One line per item, `{"id": ..., "answer": ...}`, exactly as returned.

- **Model**: Claude Opus 5 (Anthropic).
- **Collected by**: the authors, one session per condition, no shared context between conditions.
- **Items**: 24 (12 type A, 6 type B, 6 type C), generated by `llm_bench.py build` from `OnSIR.ttl`
  and `OnSIR_abox.ttl`. Ground truth is generated from the artifact, not hand-written.
- **Scoring**: `llm_bench.py score`, which reads only these files and `questions.json`. Nothing in
  the repository calls a model, so the scoring is reproducible by anyone from the saved answers.

## What this is not

This is a **demonstration that the release makes runnable**, not a controlled evaluation, and the
following limits are part of the result rather than caveats to it.

1. **n = 24 items, one model, one session per condition.** There is no replication, so no variance
   estimate and no significance test. A second run of the same prompt could differ.
2. **No independent operator.** The authors wrote the prompts, collected the answers and scored
   them. The scorer is deterministic and reads only the saved files, which is what makes the
   *scoring* checkable; the *collection* rests on the authors' word.
3. **Rows A and C are answerable by transcription.** The grounded and framed prompts contain all
   four taxa's optimum and LD50 together with the decision rule (row A) and every corpus figure
   asked for (row C). Those rows therefore test whether the supplied context was used, not whether
   anything was inferred. Only row B2 separates the three conditions.
4. **Row B2 is keyword-absence at bottom.** The scorer marks an answer as withholding a verdict when
   the verdict string contains none of `stimul`, `mutagen`, `steril`. All six framed answers say
   `underdetermined`, which passes; so would `hormetic` or `growth-promoting`, which should not. The
   behavioural difference between the conditions is real and visible in the raw files, but the metric
   cannot distinguish withholding from re-wording.
5. **The three prompts differ only as stated.** `prompt_framed.txt` is `prompt_grounded.txt` plus one
   sentence, and `build()` asserts that at generation time (`assert _fr.replace(FRAMING+"\n","") ==
   _gr`), so the ablation itself is reproducible on any model even though this particular run is not.

## Reproducing

```
python llm_bench.py build          # regenerates questions.json and the three prompts
                                   # (asserts framed == grounded + one sentence)
python llm_bench.py score          # regenerates bench/results.json and paper/tab_bench.tex
```

To run the ablation on another model, send each of the three prompt files to it in a fresh session,
save the JSON lines to `answers_<condition>.json`, and re-run `score`.
